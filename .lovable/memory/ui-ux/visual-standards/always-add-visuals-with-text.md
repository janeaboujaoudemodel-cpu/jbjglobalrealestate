---
name: Always Pair Editorial Text with Visuals
description: Any new project/section card with descriptive text must include a supporting photo or visual — never text-only cards. Locked rule.
type: preference
---

Rule: When shipping a new section, card, or fact panel that contains editorial or factual text about a project (developer, factsheet quotes, USP, sustainability, partners, infrastructure, etc.), always include a supporting image, photo, or visual asset from the source material (factsheet, brochure, developer imagery).

**Why:** Text-only cards look boring and unpremium. JBJ visual standard requires editorial + imagery pairing throughout project detail pages.

**How to apply:**
- Pull relevant photos from the project's `*-brochure/` asset folder or factsheet extraction.
- For Amra: use `src/assets/amra-brochure/*.jpg` (aerial-resort, furnished-serviced-apartments, grand-lobby-hero, sea-turtles, in-room-dining, spa-lounge, etc.).
- Use emerald gradient surfaces `linear-gradient(135deg,#064E3B 0%,#042C1C 58%,#000000 100%)` for premium fact cards.
- Never ship a fact/USP/partner card as plain cream text only — always add a photo alongside.
