REVERSED by owner decision (Aug 2026). The earlier "English-only" rule is void.

Rules:
- A developer logo must reproduce the brand's **official artwork as the developer
  itself uses it**. If the official lockup is bilingual (Arabic + English), the
  stored asset stays bilingual. Erasing the Arabic layer makes the mark look
  broken and is forbidden.
- Restored bilingual white knockouts live at
  `developer-logos/white-v2/<slug>-tight.png` and are locked/approved:
  Dar Al Arkan, Ahmed Alansari, Manazil Global, Al Fahad Holding, Abyaar,
  Dubai South, Amaya Properties, Union Properties, Lootah, Deyaar, MAG Group,
  MAG Property Development, MERED, Kifata.
- The `*-en.png` Arabic-erased variants must never be referenced again.
- NEVER use a property/render photo as a developer logo (the Sobha Realty defect:
  merged row pointed at an Emaar property webp). Every developer identity uses
  the real brand mark; Sobha Realty is locked to
  `developer-logos/white-v2/sobha-tight.png`.
- Logo artwork stays pure white on transparency, tight-cropped and centered in
  the emerald plate (`object-contain`, no clipped glyphs).
