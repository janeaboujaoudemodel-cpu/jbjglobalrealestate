---
name: No Unrequested Website Changes
description: Only change the exact website areas the user instructs; ask with options when unclear instead of deciding on their behalf.
type: constraint
---

Never change unrelated website pages, sections, copy, layout, colors, integrations, or behavior unless the user explicitly instructed it.

Never delete, remove, truncate, overwrite, deduplicate-away, or reduce database rows, imported contacts, brokerages, brokers, developers, contact details, uploaded records, assets, or business data without the user's explicit written permission for that exact deletion. Read-only fixes and additive repairs are allowed; destructive data changes require explicit approval first.

Owner-posted project content is authoritative and immutable by default. Never replace, reorder, filter out, delete, deduplicate-away, regenerate, or change an owner-selected cover photo, gallery photo, project detail, document, logo, or ordering unless the owner explicitly requests that exact change. Automated imports, enrichment, fallbacks, migrations, and performance work must preserve owner uploads and owner selections verbatim.

If a request is unclear, ask a concise question and show concrete options for the user to select before implementing.

For UI fixes, validate the exact affected area visually before claiming completion.
