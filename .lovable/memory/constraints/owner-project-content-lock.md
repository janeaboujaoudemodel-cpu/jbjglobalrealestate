# Owner Project Content Lock

Applies globally to every current and future project.

- Never delete, replace, reorder, hide, filter out, deduplicate-away, regenerate, or overwrite owner-uploaded photos, documents, logos, or project details.
- The owner-selected cover photo is authoritative and must always drive the project hero; gallery order or automated fallbacks may not supersede it.
- Imports, enrichment, performance optimization, classifiers, migrations, and fallback logic must preserve owner content and selections verbatim.
- Repairs must be additive and non-destructive. Any destructive or replacement action requires explicit written permission for the exact records involved.
- Owner uploads must use durable project media storage, never temporary/import storage.
