## The plan

### 1. Run the audits (read-only, first)

- `seo_chat--trigger_scan` — start the SEO review; list findings once it returns
- `security--run_security_scan` — RLS / exposed-data check
- Grep sitewide for: missing `<title>`, `Lovable App` defaults, non-self canonicals, hardcoded homepage `og:url` on inner pages, duplicate `id=` attrs, icon-only buttons without `aria-label`

### 2. AI-crawler & GEO discoverability (`public/robots.txt`)

Add explicit `User-agent` allow blocks for the crawlers that currently fall through to the wildcard (which has `Crawl-delay: 2`, hurting AI ingestion):

- `GPTBot`, `OAI-SearchBot`, `ChatGPT-User` (OpenAI)
- `ClaudeBot`, `Claude-Web`, `anthropic-ai` (Anthropic)
- `PerplexityBot`, `Perplexity-User`
- `Google-Extended` (Gemini training + AI Overviews grounding)
- `Applebot`, `Applebot-Extended` (Siri / Apple Intelligence)
- `CCBot` (Common Crawl — feeds most open LLMs)
- `Bytespider`, `Amazonbot`, `Meta-ExternalAgent`, `Diffbot`, `Timpibot`, `cohere-ai`
- `DuckAssistBot`, `YouBot`, `PhindBot`
- Preserve existing honeypots and admin disallows verbatim

Refresh `public/llms.txt` to point at the top public sections (services, developers, areas, guides, contact) — omit admin, CRM, dashboards, `/card`.

### 3. Sitewide JSON-LD (verify + fill gaps in `GlobalSEO.tsx`)

Confirm and, where missing, add these to the sitewide `@graph`:

- `Organization` + `RealEstateAgent` (RERA #, address, geo, phone, email, sameAs socials, logo, foundingDate, founder Person)
- `LocalBusiness` (Dubai address, `areaServed`, hours, priceRange)
- `WebSite` with `SearchAction` (`potentialAction` → `/properties?query={search_term_string}`)
- `Person` for founder (Jane Bou Jaoude)
- `BreadcrumbList` emitter for inner routes (via a small `<Breadcrumbs />` head helper)

Route-scoped schema (already partially present) will be spot-checked on: Areas (`Place`), Developers (`Organization`), Projects (`Product` + `Offer`), Guides/Articles (`Article`), FAQ pages (`FAQPage`), Services (`Service`).

### 4. Fix every SEO scanner finding

Once `list_findings` returns results, address each in the same turn: default titles, missing descriptions, non-self canonicals, missing alt text on above-fold images, icon buttons without accessible names, duplicate ids in list renderers, etc. Then `update_findings` → `state=fixed` with a one-line explanation per finding.

### 5. Sitemap sync

Re-run `scripts/generate-sitemap.ts` against the current route table + published dynamic rows (developers, projects, areas, guides). Confirm `BASE_URL=https://jbj.ae`, no admin/CRM/dashboard paths leak in, `<lastmod>` reflects DB `updated_at` where available.

### 6. Head hygiene in `index.html`

- Keep the sitewide OG fallback (JS-blind crawlers)
- Add `<meta name="theme-color">`, `<meta name="format-detection" content="telephone=no">` for iOS
- Ensure `og:image` is an absolute `https://jbj.ae/og-image.jpg`
- Confirm `<link rel="canonical">` stays out (per-route Helmet owns it)

### 7. Validation

- `npm run build` — typecheck + Vite bundle
- Re-run `seo_chat--trigger_scan` after edits
- Playwright spot-check on `/`, `/properties`, `/developers`, `/services`, a dynamic project page: confirm rendered `<title>`, canonical, JSON-LD blocks, and `robots` header
- `curl -sI https://jbj.ae/robots.txt | head` in the report
