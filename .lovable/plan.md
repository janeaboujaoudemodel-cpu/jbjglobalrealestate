

# Fix: "supabaseUrl is required" Boot Error

## Problem

The `.env` file containing the Supabase connection variables (`VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`) is missing. The Supabase client throws at initialization because `import.meta.env.VITE_SUPABASE_URL` is `undefined`.

## Root Cause

The `.env` file is auto-generated by Lovable Cloud but appears to have been deleted or not regenerated after a recent change.

## Fix

Recreate the `.env` file with the correct Lovable Cloud credentials:

```
VITE_SUPABASE_PROJECT_ID="mdafrewypkkrildjgtey"
VITE_SUPABASE_PUBLISHABLE_KEY="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJzdXBhYmFzZSIsInJlZiI6Im1kYWZyZXd5cGtrcmlsZGpndGV5Iiwicm9sZSI6ImFub24iLCJpYXQiOjE3Njc0NTA1NzgsImV4cCI6MjA4MzAyNjU3OH0.-9fLSEsMVLS38f9ca197UVYgXQGxb8g-BPrJv4ZvTp0"
VITE_SUPABASE_URL="https://mdafrewypkkrildjgtey.supabase.co"
```

This is a single-file restore. No other changes needed.
