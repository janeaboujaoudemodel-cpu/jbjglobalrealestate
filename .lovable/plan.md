

## Plan: Interactive Click-to-Edit Stamp Preview

### Current State

The stamp preview renders as a single SVG blob via `StampSVGRenderer` using `dangerouslySetInnerHTML`. There's no way to click individual elements. Text editing is done through `StampTextEditor` — a sidebar list of extracted `<text>` nodes. The SVG is generated by `generateOfficialStampSVG()` which produces labeled sections via HTML comments (e.g., `<!-- Top arc text -->`, `<!-- Separators -->`, `<!-- Center content -->`).

### Architecture

Create a new component `StampInteractivePreview` that wraps the rendered SVG and overlays transparent clickable hit zones for each editable region. When a zone is clicked, a floating toolbar appears with element-specific actions. All changes flow through the existing `svgOverrides` + `mutateTextElement` pipeline for instant live updates.

### Implementation Details

#### 1. Tag SVG Elements in `stampOfficialTemplate.ts`

Add `data-stamp-element="..."` attributes to each generated SVG element so the overlay can identify them:
- `data-stamp-element="arc-top"` on top arc `<text>`
- `data-stamp-element="arc-bottom"` on bottom arc `<text>`
- `data-stamp-element="separator-left"` / `separator-right"` on separator `<text>` elements
- `data-stamp-element="loc-top"` / `loc-bottom"` on location arcs
- `data-stamp-element="center"` on center content (monogram/logo/icon/license)
- `data-stamp-element="registration"` on registration number

#### 2. `StampInteractivePreview.tsx`

**Structure**: Renders SVG via `StampSVGRenderer`, then after mount, queries the rendered DOM for `[data-stamp-element]` nodes to calculate their bounding boxes. Overlays transparent click targets at those positions.

**State**:
- `selectedElement: string | null` — which element is selected
- `toolbarPosition: {x, y}` — where to show the floating action toolbar

**On click of an element**:
- Highlight it (golden outline/glow)
- Show a floating toolbar with contextual actions

**Element-specific toolbar actions**:

| Element | Actions |
|---------|---------|
| Arc text (top/bottom) | Edit text, adjust letter-spacing (slider), change font size, change color, toggle visibility, delete |
| Separator (left/right) | Replace style (dropdown of 12 options), resize (small/medium/large), nudge position (±2px arrows), delete, toggle visibility |
| Location arcs | Edit text, adjust spacing, change color, toggle visibility, delete |
| Center content | Switch mode (monogram/logo/icon/license/none dropdown), edit monogram text, upload logo, pick icon, change color |
| Registration | Edit text, toggle visibility, change color |

**Nudge/positioning**: For separators and center content, provide 4-direction arrow buttons that adjust position by ±1-2px. This modifies the SVG source by adjusting x/y attributes via DOM manipulation (similar to how `mutateTextElement` works). Clamped to safe zones to prevent overlap.

**Safe zone protection**: Before applying any position change, validate that:
- Text elements stay within their ring band (between outer/middle or middle/inner)
- Separators stay near the 3/9 o'clock positions (±15px max nudge)
- Center content stays within inner ring radius
- No element overlaps another

#### 3. Wire into `StampGeneratorPage.tsx`

Replace the static `StampSVGRenderer` in the center preview (lines 991-1002) with `StampInteractivePreview`. Pass:
- `svgSource`, all color/font props (same as current)
- `onSvgChange` callback → updates `svgOverrides`
- `project` for context (company name, center mode options)
- Current `localIconStyle`, `localMonogramText`, `localLogoUrl` for center toggle

#### 4. Center Content Toggle (Task 5)

The floating toolbar for center content will include a dropdown/segmented control:
- Monogram → shows text input
- Logo → shows upload button  
- Icon → shows icon picker (shield/crown/building/globe)
- License → shows registration number
- None → clears center

Switching calls `generateOfficialStampSVG` with the new `centerMode` and replaces the center portion of the SVG.

#### 5. Live Update (Task 6)

All edits use `mutateTextElement` or direct SVG DOM manipulation → `setSvgOverrides` → React re-renders immediately. No refresh needed. The `useMemo` in `LiveStampPreview` already recomputes on prop changes.

### Key Technical Approach

Rather than trying to make the SVG itself interactive (which would fight `dangerouslySetInnerHTML` + DOMPurify sanitization), the overlay approach:
1. Render SVG normally via `StampSVGRenderer`
2. Use a `useEffect` + `ref` to scan rendered DOM for `[data-stamp-element]` nodes
3. Calculate `getBoundingClientRect()` relative to the container
4. Render absolute-positioned transparent click zones at those coordinates
5. On selection, show a floating toolbar anchored near the element

This preserves all existing rendering, tinting, ink mode, and sanitization while adding interactivity on top.
